# zriz

Headless image cropper for the web with the feel of iOS Photos. Straighten with a dial, and the photo zooms just enough that the crop never shows an empty corner.

Work in progress. Docs at [zriz.dev](https://zriz.dev).

| package                         |                                        |
| ------------------------------- | -------------------------------------- |
| [`@zriz/react`](packages/react) | Unstyled React parts                   |
| [`@zriz/core`](packages/core)   | Framework-agnostic geometry and solver |

## Develop

```sh
pnpm install
pnpm dev
```

See `AGENTS.md` for every command.
